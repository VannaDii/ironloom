# API المخططات

تعيش مخططات JSON الملتزم بها تحت أدلة `schemas/` المحلية للحزم.

## انجراف المخطط

تحقق من المخططات باستخدام:

```sh
cargo run -p ironloom-schemas -- --check
```

أعد توليد ملفات المخطط بعد تغييرات العقود العامة باستخدام:

```sh
cargo run -p ironloom-schemas
```

## مخططات تهيئة وقت التشغيل

- `crates/ironloom-config/schemas/runtime-config.schema.json`
- `crates/ironloom-config/schemas/stored-setup-config.schema.json`

تصف هذه الملفات تهيئة وقت التشغيل المحلولة وشكل حمولة الإعداد المشفرة.

## عقود المصنع المرشحة

توجد العقود الجديدة في وحدات `src/factory.rs` الخاصة بكل حزمة. يطبق `Validated<T>` فحوص الحقول المتداخلة والعلاقات بينها نفسها عند الإنشاء وفك الترميز، ولا تكشف الأخطاء المنظمة الأسرار. تستخدم العدادات والمراجعات سلاسل عشرية قياسية للحفاظ على دقة المتصفح. يتشارك Rust وDart الملف `fixtures/contracts/decode.json`. لا تتطلب سجلات `FactoryArtifact` الجديدة ربطًا بسلسلة Discord، ولا يتوفر دعم للتنسيقات القديمة. هذه العقود وواجهات المحولات لا تنفذ بعد المصنع أو تسجيل الدخول أو النقل الأصلي أو الاستدلال. توضح [المواصفات المشتركة](https://github.com/VannaDii/ironloom/blob/feat/shared-factory-contracts/docs/specs/ironloom-shared-contracts.md) مسؤوليات الملفات ومسارات API وحدود تهيئة المخطط الجديد والتحقق.

تضيف المراجعة سجلًا مرتبطًا بلقطة حالة وواجهة اشتراك محدودة تصل إعادة التشغيل بالأحداث الحية، وإجابات متعددة الاختيارات ونصًا حرًا، ورسائل استدلال بأدوار ومخططات الأدوات ونتائجها، ومعرفات مستقلة للخادم والبيئة مع مفاتيح حفظ الترحيل. هذه واجهات تخضع للتحقق، ولا تزال تطبيقاتها الخلفية ومحولاتها قيد الانتظار.

تحدد المراجعة نفسها واجهات معتمدة لقراءة إعدادات الفريق والنماذج والأجهزة وتعديلها، ومراجعة الدروس وتحريرها وتغيير نطاقها وحذفها ومشاركتها، والبحث المقسم إلى صفحات في المصادر، وسجلات صريحة للمسودات وذاكرة التخزين المؤقت والموارد واستعادة المحرك. تبقى البيانات المجهولة مجهولة؛ ولا يؤكد الفشل أو طلب الإلغاء توقف التنفيذ أو تحرير الحجوزات. لا تزال التطبيقات قيد الانتظار.

لم يصدر Ironloom بعد: تهيئة مخطط جديد فقط، بلا توافق مع إصدارات قديمة أو تحويل بيانات أو تعبئة لاحقة أو ملفات ترقية أو سجل ترحيل. تزال المسارات القديمة أثناء التطوير الأولي.

يحفظ `FactoryService::create_conversation` محادثة فارغة معتمدة قبل بدء الدور الأصلي، بهوية أمر دائمة ولقطة بمؤشر صفر. لا يرسل مدخلات ولا يبدأ استدلالًا؛ وتظل مدخلات المستخدم غير فارغة.

توجد عقود الخدمة والتسجيل الأصلي المشتركة الآن في `ironloom-service::factory`؛ يعتمد عليها وقت التشغيل والمحولات الأصلية بلا أسماء استيراد قديمة. تتضمن اللقطات هوية المهمة النشطة للتحكم بعد إعادة الاتصال. سجلات المشاريع والاعتمادات والاتصالات والمصادر والتنزيلات صريحة، وتحفظ ملفات النماذج حدود التوليد عبر الإعدادات.
